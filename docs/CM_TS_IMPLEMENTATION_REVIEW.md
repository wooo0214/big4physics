## 审核中修复的问题

1. **中心力符号与单位**：交互统一γ=GM [m³/s²]、比角动量h [m²/s]、比能量ε [J/kg]；一般两体使用μ_red [kg]、κ，明确γ=κ/μ_red、h=ℓ/μ_red、ε=E/μ_red。课程、正文、词表与图轴一致。弱偏转误差分别标明相对O(ε²)、绝对O(ε³)。
2. **驱动摆收敛**：同时显示能量收支与两步长轨迹差；差异大时显著标记“具体末态与频闪结构未通过步长收敛”。小能量残差不作为轨迹准确性的证明。频闪点不连线，有限时伸长不被称为严格混沌证明。
3. **受迫振子零驱动与刚体约束**：零驱动力下相位及归一位移无定义，保留空缺；平均输入／耗散功率核验补齐。刚体控件所有角点组合满足物理惯量三角条件，相关模型明确主轴排序。
4. **热力学过程图与广延性**：等容画独立竖线，保持null而不执行null/1000；卡诺两条完整包络包含全部四段，覆盖绝热区间重叠的参数。熵参考改用固定摩尔体积V/n，规模变化满足广延性。
5. **有限热库和单态边界**：有限热库温度采用未拟合的熵前向差，保留与正则近似的非零误差；图内派生Q范围经过最坏控件组合检查。Q=0与转子l_max=0不向非法能级外推，并给单态标记。
6. **分布与近似诊断**：转子截断热容与大截断参考、遗漏权重并列；Poisson与黑体画窗不重新归一；FD固定平均数的μ求根保留残差。有限Ising、Landau平均场和玻色气体热力学极限分别标明。
7. **页面文字与性能**：热统图示标题缩为主题，操作细节保留在导语和地图；组合计数曲线避免每个采样点重建整套分布，热宽度扫描避免重复画窗积分。

## 真实页面抽查与限制

- 64关默认入口逐一打开；无答题、保存笔记或导出操作，临时来源始终0 XP。
- 日间CM1.1；夜间CM8.3强驱动／低阻尼未收敛分支；日间TS1.3高温比与小膨胀比；TS5.4温度30、截断0的失效提示；TS8.2零场两个全局最低点；TS8词表均已实测。

- 真实浏览器仅作桌面抽查；实体手机、Safari、全部64关双主题逐屏、浏览器退出再启动的持久化未测试。模拟DOM的导出／重载通过不等于这些实机测试通过。
- 强驱动数值轨迹可能不满足逐点收敛，应服从页面有效性提示。小振动、慢进动、经典稀占据、平均场等模型均只在各关给定条件内解释；本轮不新增模块综合考试、解释迁移自动评分、复习队列或服务端同步。


## 重现命令

```sh
node tests/test_cm_ts_boundaries.js
node tests/test_learning_integration.js
node tests/test_curriculum.js
node -e 'const fs=require("node:fs"),cp=require("node:child_process");for(const f of fs.readdirSync("tests").filter(f=>/^test_.*\.js$/.test(f)&&!f.includes("harness")).sort()){const r=cp.spawnSync(process.execPath,["tests/"+f],{stdio:"inherit"});if(r.status!==0)process.exit(r.status||1);}'
```
