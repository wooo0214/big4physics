# 电动力学 ED1～ED8 教学审核与中文术语修订

审核日期：2026-10-27（Asia/Shanghai）

## 结论与使用定位

**教学判断：适合作为研究生课程的交互导学、概念诊断与基础复习；尚不构成完整研究生电动力学课程。** 此判断基于现有32小节的课程文字、解析模型、题目、显示标签和回归测试，不是学校课程认证。多数原有关键推导只有少量步骤，两道选择题主要检查识别与比例关系，不能证明独立推导或综合迁移能力。

本轮保留32关及其物理模型，完成中文术语统一，修正易误导表述；每节加入一项有具体自检要点的进阶推导练习，另加116项中英文核心概念。进阶题为自评，不自动记分、不冒充模块掌握验收。

## 基础讲解精修（2026-10-27）

32小节均在原有基础折叠区按“物理问题 → 列式理由 → 关键一步 → 极限检验”重述，保持每节四段短文。基础正文参照Griffiths的讲解节奏；进阶推导与后续综合题参照Zangwill的展开深度。独立推导、边界条件、近似误差和迁移由具体任务及公共自评提示共同落实，不要求对精确恒等式虚构近似误差。

ED2.3的完整格林解式转至ED2.4进阶自检；基础区保留边界选模、唯一性及纯诺伊曼相容要求。ED5.3以正常入射为基础，斜入射s/p完整系数转入进阶自检。补强ED2.2有限圆盘迁移、ED2.3采样残差与严格误差界的区别、ED2.4多极首修正、ED5.4高频展开及ED7.4短元方向图误差。这里要求设计比较或推导误差，不宣称现有交互已实现有限圆盘求解等新模型。

保留32项进阶任务、原题正确选项与数值模型；基础讲解不代替书面推导和模块综合验收。下方逐节审核表保留此前审核记录，当前任务文字以各小节页面为准。

## 优先修订的问题

1. **ED1.2：大小与分量。** 原文一面称电场大小，一面允许它含电荷符号；负电荷时又称电场与外法向平行。现统一用带符号径向分量 Eᵣ，明确负电荷向内；|E|才是非负模长。
2. **ED5.3：全反射振幅解释。** 传播区可用实单位偏振基矢定义系数；全反射的p偏振基矢经过复解析延拓，不再是实单位矢量。因此t不能笼统叫完整电场峰值之比。保留既有复数计算及T=0的法向平均能流定义。
3. **ED4课程说明：实现边界。** ED5引入了色散，但当前无碰撞模型并不模拟耗散或吸收，已改正“频散和耗散在ED5引入”的笼统描述。
4. **名称与物理量。** 统一高斯、斯托克斯、泊松、拉普拉斯、格林、狄利克雷、诺伊曼、毕奥—萨伐尔、库仑、法拉第、麦克斯韦、菲涅耳及拉莫尔等中文用语；洛伦茨规范（Lorenz）与洛伦兹变换／力（Lorentz）分别列出。数学符号、国际单位符号和资源品牌名保留。
